## 正则实验室（regex-learning-lab）v1 完成

- 位置：`C:/Users/Sky/WorkBuddy/stu`，Vue 3 + TS + Vite + Element Plus，纯前端。
- 交付：11 章 / 45 节 / 91 示例 / 50 练习 / 13 案例；8 个页面（首页、学习三栏、实验室含对比模式、练习、随机挑战、错题本、案例、进度）。
- 核心模块：
  - `src/core/parser.ts` 手写正则 AST 解析（分组、字符集、量词、四种断言、错误容错）。
  - `src/core/explain.ts` AST → token 行 + 组合解释（不是 token 拼接，按结构重写）。
  - `src/core/evaluate.ts` 只比结果不比写法，含错因归因（拆段/过头/漏匹配/写死文本）。
  - `src/core/generate.ts` 13 个随机题生成器，mulberry32 种子，先造数据再算期望。
  - `src/stores/progress.ts` localStorage 单 store（进度/统计/错题快照）。
- 关键决策：
  - 匹配交给浏览器 RegExp，解释自己写；两层分离，三栏共用同一份计算结果。
  - 每道题/示例都带 `expect`，`scripts/verify-curriculum.mjs` 用 esbuild 打包后逐条断言（163 条）。
  - 练习判定归一化：matches / groups（展平所有匹配的 group1..n）/ count。
- 踩坑记录：
  - `String.replace` 的替换串里 `$'` 是特殊变量，用 node -e 批量改代码会把文件尾部复制进来。
    结论：改 TS 数据文件一律用 Edit/Write，不要用 node -e + replace 拼字符串。
  - Element Plus 全量引入导致主包 1.1MB（gzip 379KB），v1 接受；后续可换按需引入。
  - 无头测试用系统 Edge + puppeteer-core（--no-save），比装 Chromium 快。
- 校验命令：`npm run verify` / `npm run build` / `npx vue-tsc --noEmit`，最后一次全部通过。
